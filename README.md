# calc-hub

calc-hub is a planned website of accurate, clearly explained calculators for people in the United States and Canada.

**Status:** Phase 1 (foundation) — information pages and the build are complete. No calculators are published yet. The first five calculators are planned for Phase 2.

## Requirements

- **Node.js 24** (the project's standard, pinned in `.node-version`)
- **npm** (installed with Node.js)
- **Git** (for version control)

## Common commands

Run these in the project folder:

| Command | What it does |
|---|---|
| `npm install` | Installs the project's packages |
| `npm run dev` | Starts a local preview at http://localhost:3000 |
| `npm run build` | Builds the static website into the `out` folder |
| `npm run lint` | Checks the code for problems |
| `npm test` | Runs automated tests |
